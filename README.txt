EXPLORA PWA - combo Brasil + confirmación de traslado

Cambios incluidos:
- Vuelve el modal de traslado con botón Confirmar para evitar errores del pasajero.
- Al elegir Parque Nacional do Iguaçu ida y vuelta, los atractivos combinables de Brasil muestran solo una opción: Solo ida combinada por ARS $20.000.
- El modal explica que el precio especial se activa por haber elegido Parque Nacional do Iguaçu.
- El resumen muestra la Promo Brasil y el descuento correspondiente.
- Se mantiene el modal elegante de Borrar todos.
- Service Worker con nueva versión de caché para forzar actualización.
