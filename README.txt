EXPLORA PWA - modal de traslado en un toque

Cambios incluidos:
- Al tocar + Agregar traslado se abre el modal.
- Al tocar Solo ida o Ida y vuelta se agrega automáticamente.
- Se eliminó el botón Confirmar para ahorrar tiempo.
- La opción tocada queda marcada visualmente y el modal se cierra.
- Service Worker con nueva versión de caché para forzar actualización.

Subir/reemplazar TODOS estos archivos en GitHub Pages:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Luego hacer Commit changes. En la tablet, cerrar EXPLORA, abrir la URL en Chrome, recargar y esperar 30 segundos.
